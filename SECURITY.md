# Reporting a vulnerability

For an exploitable vulnerability, such as an update-verification bypass,
credential exposure or unauthorized device access, use GitHub's private
[Report a vulnerability](https://github.com/magnus188/aegir/security/advisories/new)
form. Include the affected commit or release, reproduction steps, expected
impact and any suggested fix. Remove credentials and personal information.

Please avoid publishing exploit details before the maintainer has had a chance
to investigate. This is a volunteer project, so no fixed response time or
security-support period is promised. Reports against current main and the
latest release are welcome; older releases do not have a maintained backport
policy.

Ordinary bugs, inaccurate readings and hardware design concerns can be reported
in [public issues](https://github.com/magnus188/aegir/issues/new/choose), unless
they also disclose an exploitable vulnerability. Describe the observed behavior
and test conditions without including sensitive information.

The analyzer is an experimental prototype. Repository security controls and
software tests do not establish suitability for breathing-gas safety. Physical
qualification is tracked in the [system review](hardware/system-review/README.md).
