# Software

[`firmware/`](firmware/) contains the ESP32-P4 application, host tests,
desktop simulator, web demo, and their build scripts. It is an ESP-IDF project:
run `make` in this directory's `firmware/` child, or use the convenience
`make` targets from the repository root.

Start with the [firmware guide](firmware/README.md). Hardware interfaces and
qualification status are documented in the
[hardware overview](../hardware/README.md).
