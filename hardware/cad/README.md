# Enclosure CAD

The active enclosure and drawings are in [revision 04](rev04/). Open the
[editable Fusion model](rev04/Trimix_Enclosure_A3.f3d) to change the design;
the [STEP assembly](rev04/Trimix_Enclosure_A3.step) is a neutral export. The
[A3 review PDF](rev04/Trimix_Enclosure_A3_Review.pdf) and
[previews](rev04/previews/) make the geometry easier to inspect.

The later [PrintReview model and print package](rev04/3d-print/) includes the
source Fusion archive, STEP export, printable parts, and PLA/PETG Bambu Studio
projects. Its [printing guide](rev04/3d-print/printing/README.md) explains
which files to use for a fit study. These are prototypes; physical fit,
sealing, temperature and gas-flow performance remain unqualified.

The latest Guition connector and cable-space study is under the
[mechanical system review](../system-review/mechanical/connector-review/README.md).
It identifies interference that the earlier A3 drawings do not resolve.
Earlier enclosure revisions remain in Git history.
