BOTTOM USB-C / ORIGINAL 85 MM WIDTH — READ-ONLY MECHANICAL STUDY
2026-10-15

Finding
The selected placement is mechanically credible enough to develop further. It
keeps the battery, display and controls in their original positions, and fits a
46.38491 x 99.8 mm connected candidate PCB outline within the original 85 mm
case width. This is a placement study, not a routed PCB or finished enclosure.

Selected placement, in original assembly/world millimetres
Main PCB core and its fitted components: translate (0, -18.9, +3.5).
Main core XY bounding box: X50.4..80.4, Y2.1..101.1; source notches retained.
Nominal 1.6 mm PCB: underside Z24.0, top Z25.6.
USB mating-mouth nominal centre: (42.5, 1.3, 27.33).
USB section transform: Xnew=42.5+Yold-29.48491;
                       Ynew=1.3+95.5-Xold; Znew=Zold+3.5.
The 1.3 mm Y coordinate is referenced to the original case datum Y0. The
original bottom wall has a slight taper, so actual recess at this height is
about 1.13 mm before a new bezel is designed.

Exact candidate substrate used by the nominal checker
Retain actual existing core laminate clipped at X80.4, then apply the core
translation. Add a tab rectangle X34.01509..51.5, Y1.3..17 and a bridge
X34.01509..51.5, Y15.5..21. The union is one valid solid. Existing STEP
laminate thickness is 1.4942 mm: its checked world Z is24.0529..25.5471.
This model offset is distinguished from the intended 1.6 mm laminate above.
The added outline is a placement envelope; it is not an approved copper layout.

Evidence
nominal-placement-review.json binds the original enclosure STEP, PCB STEP,
current PCB and fitted placement list by SHA256. All source hashes still match.
142 populated STEP model instances plus the candidate substrate were screened
against 47 retained original parts. No positive-volume collisions were found.
The nearest nominal lower-display-screw clearance is C116 at0.97428 mm;
R125/R126 have1.01790 mm. The display-retainer plate P04 is at least2.96790 mm
from the actual moved models.
component-reserve-screen.json independently checks the maximum/assembly
envelopes, including all missing models, all 19 underside components and 52
pin-tail envelopes. It passes. R125/R126 retain0.25 mm beyond the extra0.5 mm
clearance already included in those envelopes; C116 retains0.30 mm.

Required mechanical work before this becomes a usable case
1. New PCB posts and a new carrier at the shifted mounting axes (76,9.1) and
   (54.8,95.1), with new component and pin-tail relief. Old case posts, old
   carrier and old PCB screw/insert positions were explicitly excluded from
   the fixed-part check because they must change.
2. Revise lower-right cover fastening. The old M3 boss at(77,8), R4.2,
   Z30..39 blocks vertical tool access to the shifted PCB screw at(76,9.1).
   A proposed case-only alternative is approximately(77,17), with a side-wall
   web and matching lid hole. It provides about1.56 mm from a diameter4.4 mm
   PCB-screw driver gauge. Local maximum component envelopes plus0.5 mm
   clearance end atZ27.7, below that proposed boss by2.3 mm. This new boss
   has not been modeled or strength-checked.
3. New supported USB opening and clamp. Simply rotating the previous USB
   retainer is insufficient: its right insert boss near(55.51509,5.8) would
   pass through the shifted main PCB. The support/fastener arrangement needs
   redesign while preserving a positive insertion-load path and board support.
4. A shallow bottom-wall pocket for the main PCB edge. AtY2.1, a0.5 mm edge
   clearance cuts back toY1.6. Original taper leaves about1.45 mm local outer
   plastic at this height; final ribs, wall thickness and print tolerances
   remain to be designed. Q112's nominal lowest Y is2.85 after the shift.
5. Retire the original separate USB board/support parts and its lower support
   floor. Remove the old lid USB key below the lid plate. These are the same
   explicitly retired features used in the preceding case studies.

Limits
The actual housing and carrier have not been adapted for this placement, and
there is no whole-assembly insertion/removal, load, drop, cooling, cable-fit or
water-resistance qualification for this candidate. PCB routing/outline changes
and fresh electrical checks remain necessary. The reviewed main circuit can
stay electrically unchanged; only its rigid case placement changes. The USB
section and connecting routes still need implementation. Keep the source
schematics and purchased-part models unchanged.
The99.8 mm bounding length is a pricing-oriented target, not a verified quote.

Alternative screened
Keeping the main PCB fixed and adding a centred bottom USB section also had no
retained-component collision, except the expected substrate/bottom-wall pocket.
It produces a46.38491 x118.9 mm board, crossing the100 mm fabrication boundary.
The shifted-core proposal above avoids that size increase.
