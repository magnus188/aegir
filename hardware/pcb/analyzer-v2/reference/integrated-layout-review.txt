FINDING CLOSED IN THIS REVISION
The first CC1 route ran alongside an existing same-net In2 track for about
8 mm, then rejoined the retained old diagonal. That formed an unnecessary
narrow loop. The reviewed JSON removes the duplicate new copper and uses
the existing CC1 copper up to native (43.24,117.15), then branches to the
new ESD input. No original copper is removed for this cleanup. Three
sub-0.01 mm grid corrections were also replaced by direct segments.
The remaining CC1 B.Cu connection from the old terminal via to the nearby
new via is about 0.54 mm; it is a local layer stitch, not a long new loop.

ROUTING OBSERVATIONS

  input lands. Existing external connections across U901's paired lands
  are retained; no internal connection through its NC lands is assumed.
- The port-side fanout remains outside the protected routing region.
  The signal routes add no tracks on the continuous In1 ground layer.

  (47.8875,110.4675), with an inward off-pad via that avoids the existing

  adding long duplicate traces all the way from the old harness footprint.

  any footprint pad. This checked all 27 added board vias, not just the
  7 protected-side signal vias. It introduces no new via-in-pad location.
- Existing thermal via filling/capping requirements are unaffected.

MECHANICAL / ASSEMBLY HANDOFF
The rendered top view shows the original narrow core and two original
mounting holes, with USB4105 and the two ESD devices on the outward tab.
No original component or battery relocation is required by this proposal.
The current new board bounds are 45.1 × 99 mm. Its USB mouth is world X95.5,
centred at Y29.48491 using the existing PCB placement datum. The original
85 mm-wide enclosure cannot accept this tab without a local extension or
other deliberate casing change. See mechanical-review.txt for coordinates.

The enclosure work must explicitly provide:
  * A supported tab/socket load path for USB plug insertion and extraction.
  * Clearance for shell stakes/solder, the chosen cable overmould and the
    port face, plus rear board removal and both existing screw accesses.
  * Closure of the old bottom USB opening and removal of the old cartridge.
  * Preserved main-core, battery and display datums. Do not blindly change
    CaseWidth because existing expressions move other geometry with it.
The USB4105 is not a waterproof panel assembly. A printed cover does not
establish an enclosure IP rating. No native Fusion fit, stress, cable or
plug insertion test was performed in this review.
